# Fuente OWASP SAMM

`SAMM_spreadsheet.xlsx` es el archivo fuente suministrado para inicializar el catálogo.

El workbook declara OWASP SAMM v2.2.0 y su propia información de atribución y licencia en la hoja `Attribution and License`. La aplicación conserva el nombre y hash SHA-256 de la fuente en cada importación y versión generada.
